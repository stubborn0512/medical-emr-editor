# medical-emr-editor

医疗文书模板编辑器 Demo，当前以匿名化/虚构数据展示前端编辑器交互、模板排版和打印效果，仅用于界面与排版演示，不用于制作、修改或冒充真实医疗文书。

## 当前版本

- GitHub Pages 静态部署，单文件前端，无构建步骤
- CT / 超声两套匿名演示模板
- 元素树搜索与选中
- 富文本式直接编辑（contenteditable）
- 鼠标拖拽、8px 对齐吸附、中心辅助线
- 字体、字号、字重、行高、字间距、坐标、宽高控制
- 锁定、复制、删除、撤销、重做
- 只读与修订状态
- 文本/时间/单选/下拉/表格数据元入口
- 布局本地保存/载入与 JSON 导出
- 智能检查：越界、过小字号、元素重叠
- 打印专用 CSS：隐藏编辑工作台、支持半页复诊模板尺寸
- 站点访问密码门禁与当前浏览器会话锁定

## GitHub Pages

在仓库 Settings → Pages 中选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`，保存后等待 GitHub Pages 构建完成即可。
